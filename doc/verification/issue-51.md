# #51 建筑升级前置条件验证

验证目标是建筑已经建成、下一等级缺少前置时，卡片能说明具体缺什么。

## 验证步骤

使用单独的浏览器配置和开发端口准备测试存档。建筑空间留有余量，建造队列为空。

| 场景 | 准备 | 预期结果 |
| --- | --- | --- |
| 行星前置不足 | 机器人工厂 Lv 4，金属矿、晶体矿和重氢合成器均为 Lv 3，研究实验室和太阳能电站均为 Lv 1，升级资源充足。 | 「升级」按钮不可用。卡片只列出还缺的研究实验室 Lv 3 和太阳能电站 Lv 8，分别显示当前 Lv 1。 |
| 行星前置齐全 | 在上一场景基础上，将研究实验室设为 Lv 3、太阳能电站设为 Lv 8。 | 缺项提示消失，点击「升级」后，机器人工厂 Lv 5 任务进入建造队列。 |
| 月球前置不足 | 月球基地 Lv 7，机器人工厂 Lv 5。 | 卡片提示需要机器人工厂 Lv 8，当前 Lv 5。月球规则跳过了行星专属的纳米工厂，卡片也不列出它。 |
| 窄屏 | 在 390 像素宽的视口打开前置不足场景。 | 缺项文案可读，列表没有横向溢出。 |

以上场景已在 Chromium 中验证。Vue 类型检查和 `git diff --check` 通过。

本地测试存档、截图和场景切换工具放在此目录的 `local/` 下，由 Git 忽略。
